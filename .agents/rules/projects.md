# Projects Section Guidelines

- This section should be named **Projects**, not:
  - Academic Projects
  - Engineering Projects
  - Notable Projects
  - Personal Projects
  - Relevant Projects
  - Selected Projects
  - Technical Projects

---

## What to Include

- This section is for:
  - Personal projects
  - Student design teams
  - Extracurricular/hobbyist projects

- Do not include:
  - Projects from work

---

## Titles

- Don't use the word "project" in your project titles
- Capitalize your project titles correctly https://capitalizemytitle.com/

---

## Structure

- Each project should consist of **bullet points**, not paragraphs
- Order projects and bullet points based on:
  - Relevance to the job
  - Impressiveness
- Put your best work first

---

## Additional Guidelines

- For personal projects:
  - Roles/positions/locations/dates are generally unnecessary
  - Include a link to:
    - Portfolio page
    - GitHub repository

- Do not label projects as:
  - "Personal Project"
  - "Academic Project"
  - "Group Project"

---

## What Makes a Strong Project

- Should solve a real problem
- Should have actual usage (even if just by you)
- Should be actively maintained
- Should not be:
  - Mandatory school assignments
  - Trivial tutorial projects

- Consider:
  - Joining student clubs (SAE/AIAA teams, rocketry teams)
  - Mentoring FRC/FTC teams
