# GitHub & Portfolio Guidelines

---

## When to Include Links

- Include links to GitHub profiles and portfolio websites only if they are up-to-date
- If your pinned repositories lack READMEs or your portfolio hasn't been updated recently, omit them
- These links are not mandatory if they do not add meaningful value

---

## GitHub Project Quality

- Only publish projects with good READMEs
- Each README should include:
  - Summary
  - Screenshots
  - Instructions to run
  - Instructions to test

- Include tests:
  - Unit tests
  - End-to-end tests
- Tests should be runnable

## Formatting Rules

- Do not include full URLs with protocol

- Avoid:
  - https://www. github.com/bob
  - https://www. portfolio.com

- Use:
  - github.com/bob
  - portfolio.com
